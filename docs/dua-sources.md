# Adhkar — dua sources for review

Every one of the 327 supplications in the app, alongside its primary
hadith or Qur'an citation and, where possible, a direct link on
[sunnah.com](https://sunnah.com) or [quran.com](https://quran.com).

Grouped by the seven collections and their 151 chapters.

**Legend**

| | |
|---|---|
| **[Book #####](https://sunnah.com)** | resolved to a numbered hadith on sunnah.com |
| **[Qur'an s:a](https://quran.com)** | Qur'an verse resolved from the surah/āyah |
| _Hisn al-Muslim ch. N_ | reference is the book itself, not a numbered hadith. Look up the underlying hadith at [hisnmuslim.com](https://www.hisnmuslim.com/) or in a printed Hisn — a reviewer can then add a sunnah.com URL |
| **· needs check** | citation could not be resolved automatically; raw text printed below |

Regenerate with `python3 docs/build_dua_sources.py` whenever the snapshot changes.
